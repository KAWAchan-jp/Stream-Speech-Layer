# fix/hallucination-repeat-filter 作業記録

## 目的
配信音声＝英語／翻訳言語＝日本語の設定で使用中、字幕オーバーレイの原文・翻訳欄の両方に
意味不明な日本語（Whisperのハルシネーションらしき出力）が表示される事象への対処。

報告された例：
- 「これが本当に面白いです。これが本当に面白いです。これは本当に面白いです。」（ほぼ同一文の反復）
- 「トレーニングドミゲー、ストームウェンシティ、アイドゲー、」（カタカナの造語のような単語列）

## 調査結果
- `sourceLanguage`（配信音声の言語）の保存・受け渡しパイプライン（options.js → background.js →
  offscreen.js → transcriber.js）にコード上のバグは見つからなかった。
- 原文と翻訳文が同一になるコード上のフォールバックバグも見当たらなかった（`translateTranscriptIfNeeded()`は
  `from === to` の場合のみ空文字を返す設計で、原文をそのまま返す経路はない）。
- 既存の `isLikelyHallucination()`（`transcriber.js`）は定型文の完全一致リストのみ検出しており、
  同一文の反復のようなWhisperの典型的なハルシネーションパターンは一切検出できていなかった。

## スコープ
ユーザーとの確認の結果、**同一文の反復検出のみ**を今回のスコープとした（報告例1に対応）。
報告例2の「カタカナの無意味な単語列」は、実際のゲームタイトル名等と区別がつかず誤検知リスクが高いため、
テキスト規則による検出は行わない。

## 実装内容（`extension/src/transcription/transcriber.js`）
- `sentenceSimilarity(a, b)`: 文字位置ベースの軽量な類似度計算（同じ位置の文字が一致する割合）。
- `hasRepeatedSentenceLoop(text)`: `。！？.!?` で文を分割し、4文字未満の文を除外した上で、
  隣接する文のペアが2組以上、類似度0.7以上（ほぼ同一）であれば反復ハルシネーションと判定する。
- `isLikelyHallucination()` の先頭でこの判定を呼び出すように変更。既存の定型文完全一致チェックはそのまま維持。

## 検証結果
- `node --check extension/src/transcription/transcriber.js`: 通過。
- `manifest.json` のJSON妥当性: 通過。
- ロジックの手動検証（Node.jsで同一実装を動かして確認）:
  - 「これが本当に面白いです。これが本当に面白いです。これは本当に面白いです。」→ `true`（正しく検出）
  - 通常の会話文（反復なし）→ `false`
  - 「うん。うん。うん。」（4文字未満）→ `false`（文字数フィルタで除外）
  - 「ありがとうございます。本当にありがとうございます。感謝しています。」（実際にありうる感謝の反復）→ `false`（誤検知しない）
- 実ブラウザでの動作確認: **未実施**。

## 未確認事項
- 実際の配信音声・無音区間を含む状況での実ブラウザ確認。
- 報告例2（カタカナ単語列型のハルシネーション）は本修正では対応していない。今後さらに報告が続く場合は、
  音声レベル（VAD閾値）のユーザー調整UIの追加など、別アプローチを検討する必要がある。
- ユーザーの `sourceLanguage` 設定自体（配信音声の言語＝英語）が正しく保存・反映されているかは
  コード調査では確認できなかった（保存パイプライン自体にはバグなし）。実行中セッションに設定変更を反映するには
  停止→再開が必要な点も申し送り。
