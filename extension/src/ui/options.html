Stream Speech Layer 設定

認識・翻訳の設定と API キーを管理します。

おすすめ: Groq（音声認識）+ DeepL（翻訳）

どちらも無料枠だけで日常的に使えます。API キーを取得すれば追加費用なしで始められます。

  • Groq（音声認識）: 無料枠でも配信内容にもよりますが 1 日あたり おおよそ 1〜2 時間ぶんの文字起こしに使えます（目安: 1 日 2,000 リクエスト / 1 時間あたり音声 7,200 秒）。上限は翌日リセットされます。
  • DeepL（翻訳）: 無料枠（DeepL API Free）は月 50 万文字まで 翻訳できます。字幕は 1 文が短いため通常は十分な量です。 ※こちらは日次ではなく毎月リセットです。

上限日の代替: Google AI Studio (Gemini API)

Groq の無料枠を使い切った日でも、認識エンジンを切り替えれば文字起こしを続けられます。

  • Gemini（音声認識）: 使用モデルは Gemini 3.1 Flash Lite。 無料枠の上限（1 日あたりの回数など）はアカウントにより異なり、 aistudio.google.com/rate-limit で確認できます。日次上限に達すると送信を自動停止し、翌日リセットされます。 ※応答速度は Groq より遅めです。
  • キーの取得: aistudio.google.com/apikey （無料・クレジットカード不要）

ローカル認識: Faster-Whisper

自分の PC 上で動く Faster-Whisper サーバーへ音声を送り、外部 API を使わずに文字起こしできます。

  • API キー不要・外部送信なし: 音声は localhost / 127.0.0.1 のローカルサーバーにだけ送信されます。無料枠の回数制限もありません。
  • 別途サーバー起動が必要: 配布 ZIP または本リポジトリの uv/README.md を参照し、uv/ フォルダで Faster-Whisper サーバーを起動してください。 ※GPU（NVIDIA・CUDA対応）推奨です。CPU のみの場合は small モデルを選んでください。

上限エラーが出たときの対処

読み取りステータスに赤字の警告が出たら、以下を試してください。

  • Groq（音声認識）が上限: 認識エンジンを Google AI Studio (Gemini API) に切り替えてください （認識エンジンの選択を「Google AI Studio (Gemini API)」にして保存。事前に API キーの保存が必要です）。 ※応答速度は Groq より遅めです。
  • Gemini（音声認識）が上限: 日次上限（RPD）に達すると以降の送信は自動停止し、 読み取りステータスに案内が表示されます。Groq に切り替えるか、 翌日のリセットを待ってください。
  • DeepL（翻訳）が上限: 翻訳エンジンを Google Translate に切り替えてください （翻訳エンジンの選択を「Google Translate」にして保存）。 ※翻訳精度は DeepL より落ちます。

選択項目は変更するとすぐに保存されます。API キーは入力後に「保存」を押してください。

翻訳

Gemini は音声認識で使った場合も、翻訳で使った場合も、同じ Google AI Studio / Google Cloud プロジェクトの上限としてカウントされます。認識エンジンと翻訳エンジンの両方に Gemini を選ぶと、内部では1回の Gemini 呼び出しで文字起こしと翻訳をまとめて処理します。
