# プライバシー設計メモ

## 基本方針
- ユーザーの明示的な開始操作の後だけ音声取得・送信を行う
- 取得対象と送信先を UI で明確に表示する
- 文字起こし結果や音声データは必要最小限に留める

## 具体策
- 取得範囲をタブ単位に限定する
- 非同期処理で一時データを保持し、必要時のみ保存する
- 外部 API を使う場合は、送信内容と保存期間を説明可能にする
- Gemini を認識と翻訳の両方に使う場合、音声チャンクは Google AI Studio (Gemini API) へ送信され、文字起こしと翻訳を1回のリクエストで処理する
- Groq / Google Translate / DeepL / Gemini のどれを外部送信先に使うかは、設定画面の認識エンジン・翻訳エンジン選択に従う
- Faster-Whisper（ローカルサーバー）を選んだ場合、音声はユーザー自身の PC 上の `localhost` / `127.0.0.1` にのみ送信され、インターネット上の外部サービスへは送信されない。拡張は `localhost` / `127.0.0.1` 以外の URL への送信を拒否する
