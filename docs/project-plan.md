# プロジェクト計画

## フェーズ 1: 設計
- 要件と責務を整理する
- まずは YouTube Live を対象にする
- MVP で実現する機能を明確にする

## フェーズ 2: MVP 実装
- 拡張の起動と UI を作る
- タブ音声取得を実装する
- 参考実装に倣って Web Worker か offscreen で文字起こしを回す
- 文字起こしの最小連携を作る
- 表示と保存まで通す

## フェーズ 3: 拡張
- Twitch 対応
- 翻訳・字幕・エクスポート
- オーバーレイ UI 追加

## 成功条件
- ユーザーが拡張を起動して音声を取得できる
- 音声からテキストが得られる
- その結果が UI 上に見える
- ログ保存ができる
